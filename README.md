# musheur-cdn

Data files read by [musheur](https://github.com/bricadabra/musheur), served by
GitHub Pages. Generated and replaced as a whole: do not edit, do not open pull
requests.

| File | Content |
| --- | --- |
| `forests.pmtiles` | outlines of the public forests, vector tiles |
| `indicators/<dept>.json` | per-forest indicators, by department |
| `manifest.json` | fields, sources, licences, departments |
| `weather/<dept>.json` | daily weather, by department, refreshed every day |
| `species.json` | mushroom species: host trees, seasons, thresholds |

Forest outlines, tree species, elevation and terrain: ONF and IGN, Licence
Ouverte 2.0. Species seasons from GBIF occurrences.
Weather data by [Open-Meteo.com](https://open-meteo.com/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
